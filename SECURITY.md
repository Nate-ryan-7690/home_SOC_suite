# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| Latest (main) | ✅ |
| Older commits | ❌ |

Only the current main branch is actively maintained.

---

## Intended Use

This suite is designed exclusively for monitoring systems you own or have 
explicit written authorization to monitor. Unauthorized use against systems 
you do not own is illegal and prohibited.

---

## Reporting a Vulnerability

If you discover a security vulnerability in this project — for example a script 
that could be weaponized, a privilege escalation risk, or unsafe handling of 
sensitive data — please report it responsibly:

1. **Do not open a public GitHub Issue** for security vulnerabilities
2. Open a **private GitHub Security Advisory** using the Security tab in this repository
3. Describe the vulnerability, the potential impact, and steps to reproduce
4. Allow reasonable time for the issue to be assessed and patched before public disclosure

---

## Scope

This is a personal monitoring tool. The following are considered in scope for 
responsible disclosure:

- Scripts that could be repurposed to harm systems other than the user's own
- Unsafe credential or sensitive data handling
- Privilege escalation risks introduced by the scripts themselves

The following are out of scope:

- Vulnerabilities in third party services used by the suite (ip-api.com etc.)
- Issues arising from running the scripts on systems you do not own
